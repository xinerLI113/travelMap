# Night imagery

night-earth.jpg is NASA Earth Observatory / NOAA NGDC's original 2012
global night-lights composite (3600 × 1800).

Source: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/79000/79765/dnb_land_ocean_ice.2012.3600x1800.jpg

Catalog: https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/

The cached image provides continuous global coverage while finer NASA GIBS
imagery loads. It is a historical composite, not a live satellite image.
